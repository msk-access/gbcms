# The PHI list for .claude/hooks/phi-read-guard.py. Copy this file to ~/.claude/phi-paths.txt and
# put your own folders in it; the real list stays on your machine and never goes in the repo.
# (A test can name another list with the environment variable PHI_PATHS_FILE.)
#
# One entry per line. `#` starts a comment. Every entry is an absolute path (`~` and $HOME are
# read), in one of two forms:
#
#   1. A root: everything under it is patient data.
#   2. A pattern with `*` for ONE folder level, or inside a folder name: a patient arm folder
#      under any run label, or every folder of one name pattern.
#
# List every patient arm. A folder that is not listed is not guarded. The public arms
# (for example the HG002 truth arms) stay off the list.
#
# `sanitizer <absolute path>` names one more accepted sanitizer script. The default is
# ~/test/gbcms/harness/hpc/kit/phi_sanitize.py.
